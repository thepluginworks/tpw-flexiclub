## 2.10.2

This patch restores visibility for Square and Core checkout frontend errors in FlexiClub. If payment setup, SDK initialization, or card mounting fails, the checkout error container is now explicitly shown so members can see the problem instead of the message remaining hidden.

### Main changes

- Fixed the shared Square/Core payment frontend error handler so `#tpw-square-errors` is shown when an error message is present.
- Covers checkout failures such as Square SDK load issues, payment configuration problems, and card mount errors that were already being written to the error container.
- Keeps the existing error messaging path and accessibility attributes while making the rendered error state visible to users.
